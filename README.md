# DEADLINE-RUN: 2D Pathfinding Simulation (UCS & A*)

Proyek game 2 dimensi berbasis web browser yang mengimplementasikan algoritma pencarian jalur (*pathfinding*) **Uniform Cost Search (UCS)** dan **A\*** untuk menggerakkan NPC mendekati posisi Player melalui grid berpeta dinamis dengan berbagai rintangan (tembok, pohon, rumah, dan sungai).

## Kontrol Permainan & Debug
W, A, S, D atau Arrow Keys: Menggerakkan Player.

[Tombol/Key D]: Mengaktifkan / menonaktifkan Debug Overlay.

[Tombol/Key 1 - 3 / Dropdown UI]: Mengganti mode algoritma (UCS / A* Manhattan / A* Euclidean).
